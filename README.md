# TADC
Projet dans le futur d'une IA créative ou, sinon, car c'est trop dur, un programme qui arrive à reconnaître des formes géométriques sur une photo et qui assimile ces mêmes photos dans sa base de données !
<br>Pour l'instant, le répertoire TADC contient tous les fichiers de Caine in the ep8.
<br>L'objectif de ce repositories est de mettre toute création en lien avec TADC y compris mon projet d'IA.

<br><br>command.txt: fichier contenant toutes les commandes de Kinger dans l'ep8.
<br>Media/Pictures: contient toutes les images qu'a assimilées l'IA de Caine + qql screen de l'ep8.
<br>Start/the-amazing-digital-circus-lost-demo-windows: Fangame créer par Yaman Studios; j'espère qu'ils ne m'en voudront pas de mettre le fichier de la 1.1 en zip, étant donné qu'il est gratuit.
<br>Character/CA_NeutralScans[Obsolete]: Modèle Blender des persos de TADC créé par Malik Radwan.
<br>Coding/IA_Expérimentale: Plan d'étapes de mon IA (attention, le plan est sous Copyright!)

<br><br><strong>Caine est une Machine Learning discriminative et non supervisé axée sur des données ne contenant que des images. C&A est une abréviation de " Conscience Artificielle ".</strong>
